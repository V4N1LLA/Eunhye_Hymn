# 유스케이스: DEV 로그인 (개발 전용)

## 경고
- 이 엔드포인트는 **dev 프로파일에서만** 활성화된다.
- 운영/스테이징 환경에서는 절대 활성화하지 않는다.

## 목적
- Kakao 연동 전에 개발을 진행할 수 있도록 임시 토큰을 발급한다.

## 요청/응답
- 요청: `POST /auth/dev/login`
- 본문:
  ```json
  {
    "userId": "00000000-0000-0000-0000-000000000000",
    "role": "USER",
    "displayName": "개발 사용자"
  }
  ```
- 응답:
  ```json
  { "accessToken": "...", "refreshToken": "..." }
  ```

## 처리 흐름
1. 요청된 사용자 ID로 사용자를 조회한다.
2. 없으면 신규 생성, 있으면 이름/역할/마지막 로그인 시간을 갱신한다.
3. 액세스 토큰과 리프레시 토큰을 발급한다.
