# 유스케이스: 리프레시 토큰 재발급

## 요청/응답
- 요청: `POST /auth/refresh`
- 본문:
  ```json
  { "refreshToken": "..." }
  ```
- 응답(성공):
  ```json
  { "accessToken": "...", "refreshToken": "..." }
  ```

## 처리 흐름
1. 전달된 리프레시 토큰을 해시한다.
2. 저장된 토큰 해시를 조회한다.
3. 토큰이 만료되었거나 폐기되었으면 거부한다.
4. 기존 토큰을 폐기 처리한다.
5. 새 리프레시 토큰을 저장하고 액세스 토큰을 발급한다.

## 실패 케이스
- 토큰 해시가 존재하지 않음 → `401 Unauthorized`.
- 토큰이 만료됨 → `401 Unauthorized`.
- 토큰이 이미 폐기됨 → `401 Unauthorized`.
