# 유스케이스 문서

이 폴더는 사용자 흐름과 기능 시나리오를 정리한다.

## 템플릿
- **제목**: 유스케이스 이름
- **주요 사용자**: 관리자 또는 성도
- **사전 조건**: 시작 전 필요한 상태
- **정상 흐름**: 단계별 처리 순서
- **예외 흐름**: 실패/변형 시나리오
- **관련 데이터**: 영향 받는 엔티티/테이블
- **API 참조**: 관련 엔드포인트

## 주요 문서
- `admin-list-events.md`: 관리자 감사 로그/분석 조회
- `record-events.md`: 사용자 이벤트 기록
